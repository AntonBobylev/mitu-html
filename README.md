# mitu-html

Проект содержит выполненные практические задания по HTML.

## Структура проекта
- `1.html` — Задача 1.
- `2.html` — Задача 2.
- `3.html` — Задача 3.
- `4.html` — Задача 4.
- `resources/` — Директория с медиафайлами (изображения, аудио).

## Инструкция по запуску
1. Клонируйте репозиторий или скачайте архив с исходным кодом.
2. Откройте любой из файлов (`1.html`, `2.html`, `3.html`, `4.html`) в вашем браузере двойным кликом или через опцию «Открыть с помощью».
